# hxyfront-62002 剧场灯光渐变预演台

源提示词编号：2

给剧场灯光师使用的渐变预演台：预置 4 个灯位（面光 / 侧光 / 逆光 / 效果光）和 5 条 Cue，每条登记目标亮度、等待时间和渐变时长。

- 时间轴对照多盏灯的渐变窗口，撞车一眼可见
- 某盏灯上次变化未结束时，引用它的新 Cue 自动留待调整，舞台图与场景保持上一帧
- 缩短某条 Cue 的渐变后，只重排引用同一盏灯的后续 Cue（其余不动）
- 变化中的灯实时显示剩余时间，切换选中 Cue 不清零
- Cue 表与操作记录存入浏览器 localStorage，刷新不丢

## 代码结构

- `src/data.ts` —— 数据层：类型、预置灯位与 Cue、浏览器存储
- `src/engine.ts` —— 判定层：触发链编排、撞车判定、局部重排、剩余时间计算（纯函数）
- `src/App.tsx` —— 交互层：舞台图、场景、时间轴、Cue 编辑、预演时钟

## 技术栈

React + Vite + TypeScript
